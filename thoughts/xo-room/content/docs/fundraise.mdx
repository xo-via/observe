# Fundraise

<Callout>
  XO is raising a small **$500K angel round on a SAFE** to fund the next 6-8 months of focused product, reliability, and early go-to-market work.
</Callout>

This round is intentionally simple. It is not a large institutional seed, and it is not built around a long speculative roadmap. The goal is to buy enough time to turn the early OpenClaw/v1 signal into stronger retention, clearer usage data, a more reliable product, and a repeatable path to revenue.

## Category Narrative

### Product & engineering

The operating model keeps payroll controlled, but the highest-priority use of the team is still product and engineering. XO has early evidence that users want agent workspaces, especially through OpenClaw, but the product needs to become more stable, observable, and repeatable before the company scales growth.

The engineering focus is:

- Get Connect Claude working again for OpenClaw.
- Add the ability to connect to models on Hermes.
- Improve hard reset and restart flows for agents.
- Update models, channels, and identity from CLI commands.
- Update the Cowork API script and coder workspace cleanly.
- Define the agent architecture and how it evolves.
- Make it easy to turn an XO Agent into an employee-like worker.
- Complete idempotency so agents recover from crashes at the same location.

### Infrastructure, observability & data

Infrastructure ramps to **$50K/month** by November as active agents, workspace usage, and reliability needs increase. This is both a reliability requirement and a business requirement.

The capital here funds:

- Workspace compute and runtime capacity.
- Total token usage collection.
- Token collection in Claude Code and other templates.
- Logging and monitoring for background agent activity.
- PostHog for error tracking, product analytics, and usage visibility.
- Cost controls across models, workspaces, and agent sessions.

If partner infrastructure grants cover the modeled **$180K**, the cash burden of this category can be reduced to zero through November.

### Focused GTM & community

Marketing & Growth is still the largest cash category at **$260K** after reallocating $40K into payroll. That spend should not be treated as broad vanity marketing. It should stay tied to the communities and channels where product value is already showing up.

The priority is:

- OpenClaw-led growth.
- Organic word of mouth.
- Referral credits for users who invite others.
- Founder-led conversations with active users and early B2B prospects.
- Launch support when the product signal justifies it.
- Funnel experiments tied to retained users, active agents, and token flow.

The goal is not raw top-of-funnel growth. The goal is to learn which users retain, why they retain, and what makes them invite others.

### AI subscriptions & credits

AI subscriptions and credits ramp to **$50K/month** by November as token flow and agent workloads increase.

This covers model access, usage credits, agent testing, token-heavy workflows, and user activation. If partner AI credits cover the modeled **$180K**, the cash burden of this category can be reduced to zero through November. A separate **$200K AI model token-grant** pool would give XO more room for token-heavy usage above the current plan.

This spend has to support the **10T monthly token-flow** target while giving the team enough usage data to understand what agent work is actually valuable.

### Customer success, docs & templates

Operations stays constant at **$10K/month**. This is the layer that helps convert spend into retained users.

This category funds:

- Better setup documentation.
- More reliable templates.
- A Cowork API OpenAPI client so users can try the backend.
- Improved support for early OpenClaw, Claude Code, Codex, and workspace users.
- Cleaner launch paths that reduce or remove the need for users to bring their own API keys.
- Activation help for early power users.

For XO, onboarding is part of the product. If users need the team to explain every step manually, the product is not ready to scale.

### What the spend has to prove

The spend is justified if it moves XO toward **50,000 active agents**, **10T monthly token flow**, **$2M in MSA contract value**, and **100,000 users** while improving retention and reliability.

## What This Round Should Prove

By the end of this runway, XO should be able to show:

- Retention is improving across the strongest user segment.
- Organic and referral growth is starting to compound.
- Users can launch and recover agents without heavy manual support.
- The team can see token usage, agent activity, errors, and cost drivers.
- OpenClaw and related templates create a credible wedge into the market.
- XO has a sharper answer to which customers are willing to pay and why.

<Callout>
  The round is successful if XO exits this period with stronger retention, clearer usage data, and a product reliable enough to justify the next stage of capital or revenue growth.
</Callout>
