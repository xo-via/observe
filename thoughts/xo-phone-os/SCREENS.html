4-layer Pager architecture

  • Layer 1 (back): Wallpaper — themed by active mode, crossfades via AnimatePresence on commit
  • Layer 2: ModeBanner (top) — fixed, reflects active mode label
  • Layer 3: Swipeable strip — ONLY this translates with finger. N ModePage instances side-by-side
  • Layer 4 (front): WanderingVia + ModeIslandIndicator + Dock — fixed, never translates

Commit + auth check

  • Drag past 30% OR velocity threshold → commit
  • If destination mode has auth:"required" and user signed out → snap back + fire SignInOverlay
  • spring: stiffness 280, damping 32, mass 0.9

  • Slides up from bottom with spring (full-bleed dark bg)
