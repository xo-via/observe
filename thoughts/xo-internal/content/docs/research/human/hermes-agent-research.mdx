## What Is Hermes?

Hermes is a full-stack AI agent platform — a direct competitor to OpenClaw. It wraps Claude (and 30+ other providers) with:

- A persistent messaging gateway (Telegram, Discord, WhatsApp, Slack, Signal, Email, SMS, and 11 more)
- An OpenAI-compatible HTTP API at `:8642`
- A React web dashboard at `:9119`
- A stdio MCP server for Claude Code / other tools to call INTO Hermes
- A rich skill system (24 categories, markdown-based procedural memory)
- Persistent SQLite-backed sessions + markdown memory
- Multi-credential pooling with automatic failover

The current install at `/home/coder/.hermes/` was **migrated from OpenClaw** on 2026-04-20.

## Configuration System

### Three Files, One Config

Unlike OpenClaw's single `openclaw.json`, Hermes splits config across:

| File | What Goes Here | Format |
|------|---------------|--------|
| `config.yaml` | All settings (model, display, channels, tools, limits) | YAML |
| `.env` | Secrets, tokens, API keys | Shell env vars |
| `auth.json` | OAuth tokens + multi-key credential pool | JSON |

**Priority:** `env var > config.yaml > built-in default`

## Web Dashboard

**Start:** `hermes dashboard [--port 9119]`
**Default URL:** `http://127.0.0.1:9119`
**Framework:** FastAPI + Uvicorn + React/Vite SPA

**Security:** Ephemeral per-process session tokens injected into the SPA. CORS locked to localhost. HMAC validation on all `/api/*` routes.

### What It Shows

| Section | What You Can Do |
|---------|----------------|
| Sessions | Browse conversation history, search, view messages |
| Config | Live-edit `config.yaml` with schema validation |
| Env Vars | View/reveal `.env` secrets (rate-limited) |
| Auth / Providers | OAuth login flows, key status |
| Skills | Enable/disable per-skill toggles |
| Cron | Schedule editor, trigger/pause/resume jobs |
| Tools | Toolset configuration |
| Analytics | Token usage, cost tracking |
| Logs | Filtered log viewer |

### Public Endpoints (no auth needed)

`/api/status`, `/api/config/defaults`, `/api/config/schema`, `/api/model/info`, `/api/dashboard/themes`, `/api/dashboard/plugins`

## HTTP / MCP APIs

### OpenAI-Compatible API (port 8642)

Same format as OpenClaw `:18789`. The xo-cowork bridge can call either with no changes.

```
POST   /v1/chat/completions              # Stateless chat (X-Hermes-Session-Id for continuity)
POST   /v1/responses                    # Stateful Responses API
GET    /v1/responses/{id}
DELETE /v1/responses/{id}
GET    /v1/models
POST   /v1/runs                         # Async run (returns 202)
GET    /v1/runs/{run_id}/events         # SSE stream of lifecycle events
GET    /health
GET    /health/detailed                 # Rich status for dashboards
```

**Start:** `hermes gateway start --api` (or `hermes api`)

### MCP Server (stdio)

**Start:** `hermes mcp serve`
**Protocol:** stdio (JSON-RPC) — wire it as an MCP server in `.claude/settings.json`

10 exposed tools:

| Tool | What It Does |
|------|-------------|
| `conversations_list` | List all Hermes conversations |
| `conversation_get` | Get details of a conversation |
| `messages_read` | Read messages from a conversation |
| `attachments_fetch` | Fetch message attachments |
| `events_poll` | Poll for new events (200ms interval) |
| `events_wait` | Block until a new event arrives |
| `messages_send` | Send a message TO Hermes |
| `channels_list` | List configured messaging channels |
| `permissions_list_open` | List pending approval requests |
| `permissions_respond` | Approve or deny a pending tool call |

Using this from Claude Code, Claude can delegate tasks to Hermes, receive responses, list active conversations, and approve tool calls — full bidirectional control.

## Memory System

**Storage:** `~/.hermes/memories/USER.md` (markdown, human-readable)

**Injection:** Prepended to each request as `<memory-context>` fenced block (explicitly flagged as NOT user input to prevent prompt injection).

**Lifecycle:**
1. Pre-turn: retrieve relevant memory → inject into system prompt
2. Agent works with memory context
3. Post-turn: flush new facts → update USER.md
4. Every 6+ turns: compress and re-save

**Config:**
```yaml
memory:
  memory_enabled: true
  memory_char_limit: 2200        # Max chars recalled per turn
  nudge_interval: 10             # Remind to save memory every N turns
```

## OpenClaw → Hermes Migration

### How Migration Works

Two-phase process:

1. **Preview** — always runs first, shows exactly what will happen
2. **Execute** — only runs after confirmation (or with `--yes`)

```bash
hermes claw migrate                   # Preview + confirm
hermes claw migrate --yes             # Skip confirmation
hermes claw migrate --overwrite       # Overwrite existing Hermes values
hermes claw migrate --migrate-secrets # Also migrate API keys (off by default)
hermes claw migrate --preset full     # Everything including secrets
hermes claw cleanup                   # After migration: rename .openclaw → .openclaw.pre-migration
```

OpenClaw root scanned: `~/.openclaw/` (also checks legacy `~/.clawdbot/`, `~/.moltbot/`)
