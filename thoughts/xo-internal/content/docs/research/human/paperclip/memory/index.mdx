# Agent Storage & Architecture Research

This documentation covers a comprehensive research study on three multi-agent systems:

| System | Core Technology | Storage Model | Isolation |
|---|---|---|---|
| [Paperclip](/docs/research/human/paperclip/memory/paperclip) | PostgreSQL + Local Disk / S3 | Relational + file-based | Process-level |
| [OpenClaw](/docs/research/human/paperclip/memory/openclaw) | Markdown + SQLite FTS | Plain files + indexed notes | Host-level (no isolation) |
| [Claude Coworks](/docs/research/human/paperclip/memory/coworks) | VZVirtualMachine + mounts | Project-scoped memory | Full VM isolation |
| [WoterClip](/docs/research/human/paperclip/memory/woterclip) | Linear SaaS + local JSONL | Label-based state + append-only log | Host-level (no isolation) |

## Research Scope

- **File Storage** — how each system stores assets, documents, and data at rest
- **Memory Architecture** — how agents persist and recall context across sessions
- **RBAC** — role definitions, permission grants, and chain-of-command enforcement
- **Agent Structure** — how agents are configured, woken up, and coordinated
