## In Scope

The core of the Pharos engagement centers on white-labeling and customizing the XO Org backend for Helm's platform. This includes:

**Orchestration engine** — Complete agent coordination, intelligent task routing, and execution management powering Helm's platform.

**Custom theming** — Full brand identity application across dashboards, interfaces, and user-facing components without compromising underlying system integrity.

**Helm-specific UI components** — Translating XO Org's native terminology into Helm's domain language (Teams to Crews, Tasks to Missions) and building interface layers that feel native to Helm's product vision.

**Agent management** — Agent creation, configuration, capability definition, and lifecycle management within Helm's system.

**Crew orchestration and mission lifecycle** — Coordinating multiple agents across complex workflows, managing mission scheduling, execution tracking, result aggregation, and failure handling.

**Aegis security** — In scope with a key distinction: Aegis retains the XO brand and governance standards to ensure security integrity across the platform.

**Thoth integration** — Helm's proprietary onboarding wizard integrating with XO Org's backend authentication and configuration systems.

## Out of Scope

**Native mobile app** — Helm will manage mobile development independently or through other partnerships.

**Third-party integrations marketplace** — Not part of this phase, though the architecture will accommodate future expansion.

**Multi-cloud, multi-provider LLM support** — The "Bring Your Own Key" model across multiple LLM providers is deferred. Current engagement assumes a defined LLM provider strategy from Helm.

**Advanced compliance frameworks** — Audit logging for regulated industries and similar advanced compliance features are out of scope unless explicitly negotiated as a phase-two item.
