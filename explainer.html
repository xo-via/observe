observe

A folder as a universe.

Paste a path. Each top-level file and directory becomes a particle in a dark canvas sky. If the folder lives in a git repo, a scrubber appears: drag through history and watch particles morph between every commit that touched it.

Next.js 15 React 19 TypeScript Tailwind d3-hierarchy marked dev-only

What it does

Three loops, one screen. A scan reads the top level of a folder. A snapshot list reads the commits that touched it. A canvas renders each entry as a glowing particle, sized by how big it is, colored by what kind of thing it is. Choose a commit and the whole field re-lays out to that point in time.

What you see

folder
purple halo. Click to zoom in and drop into it.
.html / .htm
orange halo. Click to render in a sandboxed iframe.
.md / .mdx
sky blue halo. Parsed via marked, themed dark.
everything else
slate halo. Visible, hoverable, but no preview.

How a click flows

1 · input
User pastes a folder path into the pill at the top, presses observe. The home symbol ~ is expanded server-side.
2 · scan
POST /api/scan stats the path. With no ref, it walks the filesystem and sums bytes recursively per top-level entry (cap 5000 entries/dir, symlinks skipped). With a ref, it asks git: git ls-tree at that commit, sizes from blob metadata.
3 · snapshots
POST /api/snapshots checks if the folder is inside a git repo. If yes, git log -- . returns up to 200 commits that touched it. If no, the timeline collapses to a single live tick.
4 · pack
Universe.tsx wraps entries in a d3-hierarchy and runs the pack layout to get a resting position and radius for each particle. Folders get a value floor and grow with item count; files use log2(size) so an empty file is still visible.
5 · animate
Each frame: lerp every particle toward its target position, radius, and opacity. Add a per-particle sine wobble (random phase, frequency, amplitude). Draw a radial halo gradient plus a tiny white core, composited with lighter.
6 · scrub
Drag the bottom timeline. Selecting a commit re-issues /api/scan with that ref. Surviving entries lerp to new positions, removed ones fade out, new ones spawn near the camera and ease in.
7 · enter
Click a folder particle and the camera zooms toward it. When zoom scale crosses a threshold, onFolderOpen fires, history is pushed, and a fresh scan loads the next level. A back chip in the corner walks the stack.
8 · preview
Click a .md or .html particle and /api/file returns the content (from disk or from git show ref:path). Markdown is parsed via marked and themed dark. HTML is passed through. Either way it renders inside an iframe sandbox="" so the host page stays safe.

The three API routes

RouteMethodInputReturns
/api/scan POST path, showHidden, ref? Top-level entries with type, size, optional item count. With a ref, view comes from git ls-tree at that commit; without one, from the live filesystem.
/api/snapshots POST path { isGit, commits[] }. Up to 200 commits via git log -- ., each with sha, short sha, ISO date, author, message.
/api/file POST root, path, ref? Markdown rendered to themed HTML; HTML passed through. 1 MB cap. Path must be inside the observed root.

The three components

components/Universe.tsx

Universe

A single canvas, a particle map, a camera. d3-hierarchy lays out resting positions and radii. Each frame lerps state and draws a radial halo plus a white core. Tracks hover and click in world coordinates, fires a folder-open event after the camera passes a zoom threshold.

components/Timeline.tsx

Timeline

A horizontal bar of ticks: oldest on the left, newest on the right. Click or drag to pick a commit; the selected dot grows and gets a soft white ring. Non-git folders collapse to a single live tick so the UI never disappears.

components/Preview.tsx

Preview

A modal overlay with a sandboxed iframe. Loads /api/file, displays markdown or html for the file at the currently selected ref. esc or backdrop click closes. Truncated files show an amber badge.

Why it feels like a universe

  • Two-layer backdrop: a radial dark gradient plus a field of small twinkling stars that breathe on a slow sine.
  • Particles draw with globalCompositeOperation = "lighter" so overlapping halos add light instead of stacking opacity.
  • Every particle has its own sine wobble. The phase, frequency, and amplitude are randomized at spawn, so the field never sits still and never beats in unison.
  • Folders, html, md, and other each get their own halo-to-core ratio. Folders glow soft and wide; html and md keep a brighter core so they read as "something you can open."
  • Entering a folder is a camera move, not a route change. The scene zooms in, new particles spawn from where you were looking, the camera glides back to center.
  • Scrubbing the timeline is not a redraw. It is a re-lerp. The same particle survives its own renames, growths, and deletions if its name is stable across commits.

Limits and posture

scan budget

5000 entries per directory while computing recursive folder sizes. Past that, the sum is clipped.

history depth

Up to 200 commits per folder. Older history is cropped so the scrubber stays usable.

preview cap

1 MB per file. Larger files are truncated and the modal flags it.

symlinks

Not followed. Avoids loops and unbounded recursion through linked trees.

hidden files

Filtered by default. A checkbox in the input bar lets dotfiles through.

auth

None. The API routes read any path the server process can read. Keep this on localhost.
